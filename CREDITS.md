# Credits

## Device renders

The iPhone and Android device renders used in the Live Preview
(`src/assets/device-iphone-frame.webp`, `src/assets/device-android-frame.webp`)
come from **Creestion Studio** (github.com/dusmamud/creestion), Enzurien's own
App Store screenshot editor, where they ship as `public/screenshots/device-iphone-t.png`
and `public/screenshots/device-android-t.png`. For DrAppIcon the baked sample
UI was punched out of the screen area so the live generated icon can be
composited onto the screen plane.
